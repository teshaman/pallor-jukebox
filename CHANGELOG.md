# pallor-jukebox — Changelog

All notable changes to this module. Newest version first.
Older packaged zips are kept in `backups/` and are never deleted.

## 1.0.0 — 2026-10-28
- Initial release: API over the Youtube Player Widget (search, play, queue, next, stop, pause, resume, now, list, remove, volume).
- Jukebox playlist for tracks played or queued through the API; playlist name and default minimum search length are module settings.
- Requires fvtt-youtube-player 4.x with a Google API key in its settings.
